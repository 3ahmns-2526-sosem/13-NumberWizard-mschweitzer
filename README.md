# 13-NumberWizard-mschweitzer

## Beschreibung

Der Number-Wizard errät deine Nummer in maximal 6 Versuchen!

## Funktionen

### Buttons
- Higher:
Der geratene Zahlenbereich wird eingeschränkt, indem die "min"-Zahl guess + 1 gleichgemacht wird.

- Lower:
Der geratene Zahlenbereich wird eingeschränkt, indem die "max"-Zahl guess - 1 gleichgemacht wird.

- Restart:
Das Spiel wird neu gestartet, der guess wird zurückgesetzt, die Button sind wieder interagierbar.

### Binäre Suche
Die gesuchte Zahl wird erraten, indem die "guess"-Zahl einen minimalen & einen maximalen Wert nimmt und sie durch 2 dividiert. Der Guess ist immer die mittlere Zahl der 2 Werte (min, max).
